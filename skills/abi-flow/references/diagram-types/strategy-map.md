# Strategy map

## Use when

Connect a north-star outcome to strategic pillars, initiatives, and measurable results. Use capability map when describing what the product can do rather than how the organization will win.

## Input fields

- vision or north star
- 3–5 strategic pillars
- initiatives mapped to pillars
- measurable outcomes or key results
- causal assumptions and dependencies
- time horizon and scope

## Fixed layout

Use `TB`: vision → pillars → initiatives → key results. Keep vertical alignment between each pillar, its initiative, and its result. Avoid cross-links unless one initiative truly supports multiple pillars; split those into a shared-enabler view if needed.

## Visual rules

Use `notion` for leadership operating documents or `spectrum` for presentations. Use noun phrases for pillars, action phrases for initiatives, and metric labels for results. Do not invent targets.

## Example prompt

```text
Create a strategy-map for becoming an AI-native organization. Vision: human–AI collaboration is the default. Pillars: leading experience, reusable platform, organization adoption. Map one initiative and one supplied key result to each pillar. Use four top-to-bottom bands, notion theme, Chinese-first labels, valid DiagramSpec JSON.
```
